## Problem
The checkout flow is failing with a 400 error: `Could not find the 'coupon_id' column of 'orders' in the schema cache`. Additionally, the Edge Function `create-order` called by the frontend appears to be missing from the project's functions directory, although it is being invoked.

## Proposed Changes

### 1. Database Schema Update
- Add missing columns to the `orders` table:
    - `coupon_id` (UUID, references `coupons.id`)
    - `discount_amount` (NUMERIC)
- Ensure appropriate permissions/grants for these columns.

### 2. Edge Function Restoration
- Create the missing `supabase/functions/create-order/index.ts` Edge Function.
- The function will:
    - Authenticate the user.
    - Calculate order totals (subtotal, tax, shipping, discounts) server-side for integrity.
    - Verify coupon validity and apply discounts.
    - Create the order and order items in a transaction (or atomic sequence).
    - Return the created order details.

## Technical Details
- **SQL Migration**:
    ```sql
    ALTER TABLE public.orders ADD COLUMN IF NOT EXISTS coupon_id uuid REFERENCES public.coupons(id);
    ALTER TABLE public.orders ADD COLUMN IF NOT EXISTS discount_amount numeric DEFAULT 0;
    GRANT SELECT, INSERT, UPDATE ON public.orders TO authenticated;
    GRANT ALL ON public.orders TO service_role;
    ```
- **Edge Function logic**: Will use `service_role` client for database operations to ensure it can manage order creation and coupon usage tracking correctly.
